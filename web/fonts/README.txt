archivo-latin.woff2
-------------------
Archivo (variable: weight 100-900, width 62-125%), Latin subset.
(c) The Archivo Project Authors. Licensed under the SIL Open Font License,
Version 1.1 - https://openfontlicense.org

Bundled here, rather than linked from a font CDN, because PromptMeter makes no
network calls. The one file supplies both cuts the "Awwards" design system asks
for: Regular width (text, UI) and Extended (font-stretch: 125%, display and
buttons). It is served by promptmeter/server.py as font/woff2.
